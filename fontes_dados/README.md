# Fontes de Dados

Documentação das fontes oficiais utilizadas no desenvolvimento da Atividade Prática Supervisionada (APS).

## Fonte principal

**Sistema de Informações sobre Nascidos Vivos (SINASC)**  
Ministério da Saúde — Departamento de Informática do SUS (DATASUS).

- Base utilizada: Microdados do SINASC 2024.
- Abrangência geográfica: Estado de São Paulo.
- Unidade de observação: Declaração de Nascido Vivo (DNV).
- Período de referência: 2024.

## Acesso aos dados

Portal de Dados Abertos do SUS:

https://dadosabertos.saude.gov.br/dataset/sistema-de-informacao-sobre-nascidos-vivos-sinasc

## Utilização

Os dados foram utilizados para construir o universo de análise, selecionar as variáveis de interesse e calcular probabilidades simples, conjuntas e condicionais relacionadas ao baixo peso ao nascer.

## Observação

Os arquivos desta pasta documentam as fontes utilizadas. Os resultados e as tabelas derivadas estão organizados nos diretórios `entrada_agregada` e `resultados`.
